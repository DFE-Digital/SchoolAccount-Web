# Authenticate using DfE Sign-In (DSI)

## Context and Problem Statement

The service needs to integrate with DfE Accounts for authentication and authorisation, therefore, DSI integration is needed.

## Considered Options

* App uses its own authentication
* Microsoft Entra
* DSI

## Decision Outcome

Chosen option: DSI, because it's the strategic single sign-on solution for DfE.
